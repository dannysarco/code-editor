# @my-scrapbook/local-api

The Express server behind [My Scrapbook](https://www.npmjs.com/package/my-scrapbook): serves the browser app, exposes the `/cells` API, and persists notebooks to a local `notebook.js` file.

This is an internal piece of the `my-scrapbook` CLI — install [`my-scrapbook`](https://www.npmjs.com/package/my-scrapbook) instead unless you're embedding the server yourself.

Source and development setup: [dannysarco/code-editor](https://github.com/dannysarco/code-editor).
